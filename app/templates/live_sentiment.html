How the hybrid works

On load, the browser checks device memory and times a warmup score. Fast enough → the lexicon (~{{ lexicon_kb }} KB) loads in the background and scoring moves fully client-side, no network call per keystroke.

Looks constrained, or slows down mid-session → it falls back to this same algorithm running on the server, debounced, with stale in-flight responses cancelled so a slow reply can't overwrite a newer one.

Words outside the lexicon are ignored automatically. Negators (not, never, no...) and intensifiers (very, extremely...) within {{ negation_window }} words before a sentiment word flip or scale its contribution — the only "stop words" treated specially.

How this works

Every animation frame, a deterministic reflex reads the game state and picks {{ prof.seed_taxonomy.keys()|join(' / ') }} -- no network call, so it plays fine offline.

When the reflex flags a call ambiguous (the obstacle sits right at the edge of the jump window), it also asks the server -- throttled, cancelled if superseded -- for a second opinion from a configured model. The server review never overrides the reflex mid-air; it only nudges the reflex's own threshold for next time.

Escalation model for this mode: {{ prof.backend }}, changeable in config.py, an env var, or per request -- the reflex layer itself never depends on it.
